VELTRO HTS Windows 설치

최초 한 번만 설치하면 이후 버전은 프로그램이 자동으로 확인하고 다운로드합니다. 설치 후 바탕화면과 시작 메뉴에서 VELTRO HTS를 실행할 수 있습니다.

Windows 10/1164-bit자동 업데이트
VELTRO HTS 최신 설치파일 다운로드
새 버전이 배포되면 설치된 HTS가 자동으로 다운로드합니다. 업데이트 다운로드가 끝나면 즉시 재시작하거나 프로그램 종료 시 자동 적용할 수 있습니다.

※ 현재 설치파일은 코드서명 인증서가 적용되지 않은 경우 Windows SmartScreen 경고가 표시될 수 있습니다.

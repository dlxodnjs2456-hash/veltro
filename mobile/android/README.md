# VELTRO Android

Android wrapper for the existing VELTRO WTS.

- App version: 1.0.0
- Package: `kr.co.veltro.mobile`
- Start URL: `https://veltro-n8v3.vercel.app/`
- This project does not modify the existing WTS, HTS, Supabase schema, balances, orders, positions, deposits/withdrawals, notices, or notifications.

The GitHub Actions workflow builds an installable test APK and publishes it as a workflow artifact and Android GitHub Release.
